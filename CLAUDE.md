## Концепция
Сайт «Полина, ты работаешь?» — портфолио графического дизайнера в формате визуальной новеллы. Посетитель попадает в комнату дизайнера, общается со стилизованной мультяшной Полиной через диалоговое окно внизу экрана, выбирает варианты ответов и исследует её творческий мир.
Стиль: современная 2D-иллюстрация в эстетике японских визуальных новелл.
Палитра: розовый, кремовый, белый, светло-бежевый, приглушённый малиновый.
Интерфейс аккуратный, без лишнего декора.

## Принятые решения
- Только версия для компьютера. На телефонах показывается заглушка в стиле сайта: картинка Полины, фраза «Загляни ко мне с компьютера», контакты и ссылки. Архитектура должна позволять добавить мобильную версию позже.
- Первый экран: сразу комната и приветствие Полины.
- Повторный визит: сайт запоминает посетителя (в его браузере), Полина говорит «О, снова ты!» и сразу предлагает выбор разделов.
- Только русский язык. Без звука. Без статистики посещений.
- Сценарий пишет Полина. Текст хранится в отдельном файле.
- «Обо мне»: текст и, возможно, фото. Контакты: только ссылки. Проекты: картинки с коротким описанием.
- У каждого раздела своя прямая ссылка. Есть быстрое меню: Портфолио, Обо мне, Контакты, Начать сначала.
- Бесплатный хостинг с бесплатным адресом (Netlify или Cloudflare Pages), код хранится на GitHub.
- Диалог: текст печатается по буквам, клик во время печати показывает реплику целиком, следующий клик показывает следующую реплику.

## Комната и кликабельные предметы
- Монитор → Портфолио (камера приближается к экрану, затем стилизованный рабочий стол).
- Доска-мудборд на стене → Обо мне.
- Смартфон на столе → Контакты (окно со ссылками).
- Пасхалки с репликами Полины: кружка кофе, скетчбуки или банка с карандашами, окно или растение.
- При наведении предмет подсвечивается мягким контуром и показывается подпись.
- Фон: холст 3360×1600 px, основная зона 2560×1440 px по центру, края — запас для широких экранов. Каждый кликабельный предмет — отдельный PNG того же размера холста.
- Персонаж — отдельные спрайты PNG на каждую эмоцию, одинаковый размер холста и положение фигуры. Имена файлов по эмоциям: neutral, smile, thinking и т. д.

## Портфолио
Рабочий стол с папками: Плакаты, Фирменный стиль, Упаковка, Книжный дизайн, Иллюстрации, Другое. Папки открываются, проекты смотрятся в отдельных окнах с галереей. Добавить проект = скопировать папку проекта, заменить картинки и текст.

## Технологии
React + Vite + TypeScript, анимации на Motion, контент в файлах YAML и Markdown, GitHub + бесплатный хостинг с автоматической публикацией и отдельными черновыми ссылками для проверки этапов. Изображения оптимизируются автоматически.

## Структура контента
```
content/
  dialogues/main.yaml — сценарий
  characters/polina/*.png — эмоции
  about.md — «Обо мне»
  contacts.yaml — ссылки
  portfolio/{posters, branding, packaging, books, illustrations, other}/<проект>/
    project.md (title, year, client, tags, order + описание), cover.jpg, 01.jpg, 02.jpg…
```
